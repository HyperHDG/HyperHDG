# jprecond

## Requirements

- git lfs
- zlib,zstd,bz2,lzma compression libraries (should only depend on zstd but is not configured properly).

## Compilation

`cmake -B build && cmake --build build --target make_geo`

Some other targets related to `fmtlog-shared` are seemingly not building, but can simply be ignored.
That should be fixed soon.

## Run

```sh
build/experiments/make_geo <input_folder_path> <output_path>`
```


where `<output_path>` can either be a folder or a writable path.

This produces a `*.geo.bin.zstd` file.

Next:

```sh
experiments/fiber_network_experiments.py <network>
```

where `<network>` is the full path to the file previously generated by `make_geo`.
Use `-h` to see a full list of options controlling relative tolerance and output.
